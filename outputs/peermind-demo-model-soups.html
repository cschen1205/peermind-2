    How this defender is designed

    Part 1 · Evidence-based MAS: the coordinator scopes the critique and generates specialists from its content. Specialists inspect source-linked paper evidence and counter-evidence, then reconcile their observations in one evidence ledger.

    Part 2 · Counterfactual Verifier: the verifier fixes one causal question, constructs a baseline, a targeted intervention and an unrelated control, applies the same decision rule to all three, checks whether the response is specific to the targeted change, and returns a bounded counterfactual verdict.

    Boundary: a simulated edit can test response sensitivity, but it cannot create an unperformed proof or experiment. Unavailable substantive interventions remain incomplete and never count as successful repairs.

    Proposed system design

    An investigation for every critique.

    Paper understanding leads to candidate critiques. The defender investigates each one, and the report shows only the verdicts supported by completed investigations.

    01 / UNDERSTAND THE PAPER

    Build a source-linked graph

    Extract contributions, author claims, method, data and experiments with source references. An extracted claim is not an established fact.

    02 / REVIEW THE PAPER

    Build a complete review

    The graph determines specialist roles. An editor synthesizes the overall assessment, strengths, paper-wide reasoning, requests for evidence, author questions and detailed comments, preserving their source context.

    03 / RESPOND TO THE REVIEW

    Defender interprets and plans

    The coordinator distinguishes factual allegations, scientific judgments, experiment requests and author questions, then generates specialists and a response plan. Evidence gaps trigger bounded replanning; clarification can remain awaiting the author.

    04 / INVESTIGATE

    Call tools and challenge reasoning

    Search paper evidence, resolve references and check calculations. Where useful, edit a sandbox copy and ask the reviewer to reassess the same issue, using an unrelated edit as a control.

    05 / SYNTHESIZE

    Return evidence and a verdict

    Combine tool results and defender observations to assess whether the critique is true and whether its importance is justified. Evaluate whether a targeted revision materially strengthens the paper. A failed sensitivity check alone does not refute an otherwise valid criticism.

    06 / REPORT

    Publish completed findings

    The report updates as each investigation finishes. Untested critiques remain “Not checked”; evidence edits stay inside the investigation of the source paper.

    What “verified” can mean

    VerifiedDirect evidence or calculation establishes a bounded factual allegation.
    Supported concernEvidence supports a concern requiring scientific judgment.
    RefutedCounter-evidence defeats the allegation.
    UnverifiedEvidence or tool access is insufficient.
    DisputedCredible conflicting evidence remains unresolved.

    How we would evaluate it

    For future evaluation, use independently labeled defects and controlled evidence interventions within the defender’s investigation. Assess final critique accuracy as well as appropriate reviewer updates.

    MetricQuestion
    Defect recallDid it identify the planted defect?
    False-positive rateDid it allege a defect that is absent?
    Refutation accuracyDid counter-evidence defeat the false critique?
    Evidence accuracyDoes the cited passage establish the verdict?
    Unrelated-finding stabilityDid untouched findings retain their verdict?

    A fixture is clean only with respect to the tested defect. No performance metrics have been measured in this frontend prototype.
